# crawlop CLI

Installed by `pip install -e .`; implementation is `apps/api/crawlops/cli.py`. Run `crawlop --help`. Configure `CRAWLOPS_URL` and `CRAWLOPS_TOKEN`, or obtain a session token with `crawlop login`. Archive deployment, image deployment, project creation/listing, version-aware spider listing, execution, log following, cancellation, rerun and schedule listing call actual REST endpoints.
